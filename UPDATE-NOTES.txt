물고기는 어디에 · 10월 20일 흐름 수정

적용 방법
1. 압축을 풀고, 기존 프로젝트에 같은 경로로 10개 파일을 덮어씁니다.
   shared/phone-sync.js와 interactions/fish05.js는 각각 해당 폴더 안에 넣습니다.
2. VS Code에서 저장한 다음 GitHub Desktop에서 Commit → Push origin을 합니다.
3. Render에서 연결한 서비스의 Deploy latest commit을 실행하고 Live를 확인합니다.
   server.js까지 함께 배포해야 물 주기와 마지막 초기화가 동작합니다.
4. 폰과 아이패드 화면을 모두 새로고침하고, 아이패드의 디스플레이 시작하기를 누릅니다.

접속 주소
폰 홈: https://test1-e3hn.onrender.com/
NFC: https://test1-e3hn.onrender.com/?fish=fish05&phase=water
아이패드: https://test1-e3hn.onrender.com/display.html?fish=fish05

바뀐 흐름
- 기울기 연결 버튼을 삭제했습니다. 센서가 허용되어 있으면 자동으로 연결합니다.
  권한 요청이 필요하면 기존 화면을 터치할 때 요청합니다.
- 시작하기 → 첫 안내 → 화면 터치 → 소녀에게 가까이 가기(NFC 대기).
- NFC 태그 → 물 주기 안내 → 화면 터치 → 물 배경만 표시.
- 물이 화면 위쪽 모서리에 닿아 넘칠 때 실제 물의 양이 줄어듭니다.
  되돌려 세워도 이미 부은 물이 다시 채워지지 않습니다.
- 남은 물이 전체 화면의 35% 이하이고 S1_water 영상도 끝나야 S1_main으로 넘어갑니다.
  물을 충분히 주면 남은 영상은 끝까지 재생합니다.
  영상이 먼저 끝나면 마지막 프레임에서 충분한 물을 줄 때까지 기다립니다.
- S1_main 종료 → 수도꼭지 첫 말풍선 → 터치 → 두 번째 말풍선 → 터치 → 게임.
- 게임 성공 → S1_ending 1회 재생 → 물고기 등장 말풍선.
- 말풍선은 터치로 다음 단계로 넘어갑니다. 마지막 기다림 안내를 터치하면
  물고기 보내기 버튼이 나옵니다.
- 물고기 보내기 → TD 신호 1회 → 폰은 로고, 아이패드는 S1_walk로 즉시 돌아갑니다.
  S1_ending을 다시 재생하거나 4초를 더 기다리지 않습니다.
- 폰 화면은 기기 비율에 맞춰 배경을 채웁니다.

조정할 값(config.js)
home.pourRate: .22          물이 넘칠 때 초당 줄어드는 양(화면 전체=1)
home.pourCompleteLevel: .35 다음 단계로 갈 수 있는 남은 물의 양
common.finishWithButton: true 마지막 수평 감지 대신 버튼 사용(현재 시연 설정)

확인한 항목
JavaScript 문법, 물 기울기·유출·초기화 계산, 폰↔아이패드↔TD 모의 연동,
센서 자동 허용/첫 터치 권한 요청/구형 Android 방식,
물의 양과 영상이 끝나는 순서 양쪽, 연결 재시도, 마지막 초기화·TD 신호 중복 방지.
실제 버디3와 아이패드에서의 센서·영상 재생은 배포 후 확인해주세요.
