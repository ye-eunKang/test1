영상 + GIF 방식 복구본

프레임 방식으로 변경하기 직전의 코드 8개를 그대로 복구합니다.
- 아이패드 물 붓기: assets/S1_water.mp4 영상
- 폰의 걷는 소녀: assets/intro_girl_walk.gif
- 물의 양에 따라 영상 속도를 조절하던 이전 방식으로 돌아갑니다.
- 프레임 표시용 스크립트 연결과 프레임 설정을 제거합니다.

적용 방법
1. 압축을 풀고 파일 8개를 기존 프로젝트의 같은 위치에 덮어씁니다.
   shared/phone-sync.js는 기존 shared 폴더 안에 덮어씁니다.
2. GitHub Desktop에서 Commit → Push origin을 누릅니다.
3. Render 배포가 Live로 바뀌면 폰과 아이패드를 모두 새로고침합니다.
4. 아이패드의 디스플레이 시작하기를 다시 누르고 NFC 흐름을 시작합니다.

원래 assets/S1_water.mp4와 assets/intro_girl_walk.gif를 사용합니다.
